# LinkLine 1.0.2

修复 Windows 安装许可正文的中文乱码，并适配更名后的 LinkLine GitHub 仓库。提供 Windows 10 / 11 x64 安装包；1.0.0 和 1.0.1 的发布记录与文件继续保留。

## 修复与调整

- 为安装程序使用的许可文本明确标识 UTF-8 编码，修复中文正文显示乱码的问题。
- 仓库正式更名为 [`yaonikaixin999999/LinkLine`](https://github.com/yaonikaixin999999/LinkLine)，同步关于页、项目链接、官方检查更新及下载地址。
- GitHub 官方源在 API 限流、Atom 订阅不可用时，回退读取本仓库的官方发布清单；仍使用官方安装包下载地址，并校验仓库及版本身份。
- 国内更新采用 `updates/stable-linkline.json`，同时维护旧版兼容清单 `updates/stable.json`，供已发布的 1.0.0 / 1.0.1 国内更新入口使用。

完整功能和平台支持范围见[项目说明与使用手册](https://github.com/yaonikaixin999999/LinkLine/blob/main/docs/项目说明.md)。

从托盘退出正在运行的旧版后，运行完整安装包升级。国内加速由第三方代理提供，可切换官方或备用入口；软件不会在后台自动安装。
