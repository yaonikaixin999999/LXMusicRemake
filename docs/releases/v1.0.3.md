# LinkLine 1.0.3

LinkLine 1.0.3 将本地音乐、目录搜索和窗口行为相关功能纳入正式 Windows x64 发行版，并修复歌曲列表中的元数据跳转体验。

## 新增与修复

- 新增独立「本地音乐」库，支持选择音频文件或递归扫描文件夹导入，导入数量不设上限，支持进度显示、取消和继续导入。
- 排行榜、精选歌单、音乐库、搜索结果、歌单详情和平台目录中的歌曲列表支持点击歌手名称搜索歌手、点击专辑名称搜索专辑。
- 点击歌曲名称仍然播放歌曲，点击专辑链接不会误触发播放；相同条目再次点击会返回对应搜索结果。
- 优化跨平台播放回退与音质偏好，设置页和播放栏使用同一份音质配置。
- 新增关闭窗口询问、最小化到托盘、后台播放和托盘恢复，保留用户的关闭行为选择。
- 桌面歌词增加背景透明度设置，并改善歌词窗口的位置恢复和小尺寸布局。
- 更新 LinkLine 项目文档、更新清单和安装包校验信息。
