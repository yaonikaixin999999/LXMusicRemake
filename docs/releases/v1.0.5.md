# LinkLine 1.0.5

LinkLine 1.0.5 修复滚动条显示、音乐库面板配色和播放资源累积问题，默认按当前账号权限选择最高可用音质。

## 更新内容

- 外观定制新增「隐藏滚动条」开关，默认开启。隐藏歌单、歌曲列表和歌词等区域的滚动条，同时保留鼠标滚轮、触控板和键盘滚动。
- 音乐库左侧歌单面板和右侧歌曲面板使用统一背景，浅色和深色主题下保持一致。
- 修复主窗口与桌面歌词频谱平均值跨帧累加的问题，减少长时间播放时的无效绘制计算。
- 下载 Worker 改为按需创建；音效解码缓存改为有数量上限的 LRU 缓存，合并重复请求并清理结束后的请求状态。
- 修复下一首预加载失败后的状态复位，减少播放资源长期驻留。
- 默认音质命名为「账号最高音质」，根据当前平台、歌曲与账号权限自动选择最高可用档位。废弃旧播放栏独立缓存，避免它覆盖默认音质；设置与播放栏共享同一偏好，并保留用户主动保存的固定档位。

本次优化针对已确认的资源累积与不必要驻留。Electron 包含主进程、界面、GPU 等多个进程，实际总内存仍受歌曲封面、歌词、音效、登录窗口及使用时长影响，不设定固定占用数值。
