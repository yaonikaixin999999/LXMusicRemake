# LinkLine 1.0.1

1.0 系列的界面修正版，提供 Windows 10 / 11 x64 安装包。1.0.0 首版及其发布文件继续保留。

## 修复

修复官方备用更新源返回安装包、但未提供 SHA-256 校验值时，更新中心错误提示「此版本未提供 Windows x64 安装包」的问题。

安装包下载入口按照实际文件是否存在展示；缺少校验值仅影响校验信息显示，不再与安装包缺失混淆。

## 下载与升级

- 安装包：`LinkLine-v1.0.1-x64-Setup.exe`。
- [GitHub 官方下载](https://github.com/yaonikaixin999999/LinkLine/releases/download/v1.0.1/LinkLine-v1.0.1-x64-Setup.exe)。
- [国内加速下载](https://gh-proxy.com/https://github.com/yaonikaixin999999/LinkLine/releases/download/v1.0.1/LinkLine-v1.0.1-x64-Setup.exe)。
- [国内备用下载](https://ghfast.top/https://github.com/yaonikaixin999999/LinkLine/releases/download/v1.0.1/LinkLine-v1.0.1-x64-Setup.exe)。
- [SHA-256 校验文件](https://github.com/yaonikaixin999999/LinkLine/releases/download/v1.0.1/SHA256SUMS.txt)。

从托盘退出正在运行的旧版后，运行完整安装包升级。国内加速由第三方代理提供，可切换官方或备用入口；软件不会在后台自动安装。

完整功能与操作：[项目说明与使用手册](https://github.com/yaonikaixin999999/LinkLine/blob/main/docs/项目说明.md)。首版功能记录：[1.0.0 发行说明](https://github.com/yaonikaixin999999/LinkLine/blob/main/docs/releases/v1.0.0.md)。
