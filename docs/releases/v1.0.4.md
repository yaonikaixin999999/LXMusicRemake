# LinkLine 1.0.4

LinkLine 1.0.4 优化了更新体验、播放资源释放和长时间运行时的内存占用，并移除了侧栏中不必要的滚动条显示。

## 更新内容

- 启动检测到新版本时自动打开更新中心。
- 更新中心支持应用内下载 Windows x64 安装包，显示实时进度、下载速度和校验结果，下载完成后可直接启动安装。
- 支持 GitHub 官方源、国内加速源和备用下载源，下载地址仅接受 LinkLine 官方 Release 文件。
- 修复 QQ 音乐歌曲 ID 查询的 Promise 长期驻留问题，并限制歌单、排行榜和平台缓存大小。
- 播放预加载音频、媒体封面和桌面歌词通信资源会及时释放，降低长时间运行的内存增长。
- 隐藏不必要的侧栏滚动条，同时保留内容滚动能力。
